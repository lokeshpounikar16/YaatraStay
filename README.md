# YaatraStay

Run the website and reservation backend locally with:

```powershell
npm start
```

Then open [http://localhost:3000](http://localhost:3000). Reservation requests are validated and saved in `data/reservations.json`.


For a development-only view of saved reservations, open [http://localhost:3000/api/reservations](http://localhost:3000/api/reservations).
